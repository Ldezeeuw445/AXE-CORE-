One plate, three layers.

The glass plate is a canvas. Everything AXE shows is an object placed on it — a card, a 3D scene, a phone, a chart. One light model for all of them: light from above, depth from below, color only in ink. Only the plate flips between glass and black; what lies on it stays the same.
