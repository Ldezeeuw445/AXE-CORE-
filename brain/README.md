# brain/ — wat waar blijft

De rest van de documentatie beschrijft **wat vandaag geldt**: welke taken open
staan, wie waaraan werkt, welke sleutel waar woont. Die bestanden veranderen
dagelijks, en dat hoort.

Hier staat wat **niet** dagelijks verandert: wat AXE Core is, hoe de handel in
elkaar zit, hoe het geheugen werkt, hoe er geschreven wordt. Dat verschil is de
hele reden dat deze map bestaat. Wie een taak oppakt zonder dit gelezen te
hebben, leidt het opnieuw af uit de code — en dat is precies waar sessies langs
elkaar heen gaan werken.

In gewone taal, niet in codepaden. Een bestandsnaam die hier staat is over drie
weken verhuisd; een uitleg van hoe iets werkt niet. Noem code alleen waar de
naam zélf de val is — `noteRetrieval` staat er daarom wel in, omdat je hem
anders nooit vindt.

| Bestand | Waarvoor |
|---|---|
| `product.md` | wat AXE Core is, voor wie, en wanneer het goed is |
| `stem.md` | hoe er hier geschreven en gebouwd wordt |
| `geheugen.md` | hoe AXE onthoudt en leert |
| `handel.md` | hoe de handel werkt: accounts, ledger, frameworks |

Klopt er iets niet meer, verander het hier. Een fout in deze map is duurder dan
een fout in de code: elke sessie begint ermee.
